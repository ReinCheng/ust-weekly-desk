# UST Weekly Desk

纽约时间的美国国债周度前瞻与复盘。本站汇总公开日程、国债拍卖结果和财政部收益率曲线。

每周日纽约时间 18:00，GitHub Actions 从公开来源核对上一周、本周和下一周，更新 `calendar.json` 并发布。部分来源暂时不可用时，保留该来源最近可用的数据与核对时间。

浏览器中的重点标记、待确认事项、复盘和归档存于当前浏览器。公开日程可跨设备查看，各设备的个人记录各自保存。

本地预览需 Node.js 24 和 pnpm 11。运行 `pnpm install --frozen-lockfile`、`pnpm run build`，然后用静态 HTTP 服务打开 `dist/`。
